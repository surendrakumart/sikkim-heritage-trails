# Sikkim Heritage Trails

An interactive digital heritage trail experience for Sikkim.

## Highlights

- Six-stop heritage journey: Gangtok, Himalayan Forest, Sikkimese Village, Paddy Fields, Scenic Viewpoint, and Rumtek Monastery
- Interactive trail map and chapter progression
- Immersive drag-to-look scene exploration
- Sequential image/details navigation
- Landmark-focused Then ↔ Now comparisons
- Heritage journal and badges
- Responsive mobile-first interface
- Subtle motion, counters, ambient effects, and progressive reveal animations

## Run locally

This prototype is a standalone HTML website. Open `index.html` in a modern browser, or serve the folder with any static HTTP server.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Tech

HTML, CSS, and JavaScript for the current working prototype. External fonts, icons, and some imagery are loaded from their respective hosted URLs.
